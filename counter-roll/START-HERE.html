THE COUNTER-ROLL · PHASE ONE

Start here

This is the app as a folder on your own computer. Nothing is published. Your entries stay in one file inside the folder.

What you need

A Mac or a Windows computer, and an internet connection. The first run downloads some helper packages and fonts.

Plan on about 15 minutes the first time. Later starts take a few seconds. You do not need an account anywhere.

Set up, once

1

Install Node.js

Node.js is the engine that runs the app. Go to nodejs.org. Download the version marked LTS. Open the file and click Next (Windows) or Continue (Mac) until it finishes. The default choices are fine.

2

Unzip the app

Double-click counter-roll-phase-one.zip. On Windows, right-click it and choose Extract All. You get a folder called counter-roll. Move it somewhere easy, such as your Desktop.

3

Open a terminal inside that folder

A terminal is a window where you type short commands. You only need three of them.

WindowsOpen the counter-roll folder. Click the address bar at the top of the window. Type cmd and press Enter. A black window opens.
MacOpen the Terminal app: press Command and Space, type Terminal, press Enter. Type cd and a space. Drag the counter-roll folder from Finder into the Terminal window. Press Enter.
4

Check that Node is there

Type this and press Enter:

node --version

If you see v22 or a bigger number, go on. If you see an error, close the window, open a new one as in step 3, and try again. A window that was open before the install does not know about Node.

5

Install the app's parts

npm install

Wait one to three minutes. Lots of lines scroll by. Yellow warnings are normal. It is done when the window lets you type again.

6

Start the app

npm run local

The first time, it builds the app. That takes a minute or two. When it is ready, a box appears with an address and a passcode.

7

Open it in your browser

Go to this address in Chrome, Safari, Edge or Firefox:

http://localhost:3000

Type the passcode: counter-roll

Keep the terminal window open while you use the app. Closing it stops the app.

What to look at

The tabs along the top are the screens. A good order:

  1. Converter. Answer the four questions about how you meet your own misses. Save. This sets one number that the other screens use.
  2. Place. Name any rule, routine or promise from your life. Answer the seven questions. Watch the dot on the map move and the arithmetic print as you answer. Press place it.
  3. Rebuild. This opens after you place something. Change one answer at a time and watch the dot travel. Save a rebuilt version if you like.
  4. Log. Everything you placed. Use the two menus at the top to see the same entries under other weights.
  5. Pattern. Appears once you have placed three things.
  6. Examiner. Log a miss. The timer starts when you pick the first sentence and stops when you press second sentence done.
  7. Weights. Move a slider and see every placement recompute before you save anything.
  8. Data. Bring in entries from the old single-page version, or download everything as JSON or CSV.
  9. Mechanism. The explanatory scenes from the original page, as interactive pieces.

The sentences, the questions and the arithmetic come from the original page and the scoring file. If a word or a number looks wrong to you, note which screen it was on. That is exactly what this review is for.

Stop and start again

To stop: click the terminal window and press Ctrl and C together. Or just close the window.

To start again: open a terminal in the folder (step 3) and type npm run local. Your entries are still there. This time it starts in a few seconds.

Start from nothing

Stop the app. Inside the counter-roll folder, delete the folder named data. Start the app again. All entries are gone and you begin clean. Delete only that folder.

If something goes wrong

"npm" or "node" is not recognized, or command not found
Node is not installed yet, or the terminal was opened before you installed it. Install it (step 1), then open a new terminal.
It says you need Node.js 22 or newer
Download the current LTS from nodejs.org, install it, open a new terminal, and run npm run local again.
The build stops and mentions fonts or the network
The build needs the internet for fonts. Check your connection and run npm run local again.
"Address already in use", or port 3000 is busy
Another program is using that address. On Windows type set PORT=3001&& npm run local. On Mac type PORT=3001 npm run local. Then open http://localhost:3001.
The page says it is not the passcode
The passcode is counter-roll, all lowercase, with a hyphen. It lives in a hidden file called .env.local inside the folder. On a Mac, press Command, Shift and Period in Finder to show hidden files.
Anything else
Select the last 20 lines in the terminal, copy them, and send them to me with a note about which step you were on.
