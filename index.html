For a long time, the answer has been the universe.

To find the right questions, we built phenomenal instruments — and bought the time to keep asking.

They work.

Here, the answer is you.

What do we ask now?

Everything we have ever discovered was already there before we found it. The answers were never the bottleneck — the questions were.

A question is only as good as the mind that asks it — so the long project of our species has been growing that mind. We look outward by nature. The universe hides nothing; it waits for us to know enough to ask. So we built instruments that see farther than any eye, minds that think beside our own — and we guard our survival fiercely, so someone is always here to keep looking. All of it points one way: out. What never got examined is the eye behind the instruments — the one doing the asking. Here, that same momentum turns around. If the answer is you, the first question is already waiting: what, exactly, is this “you”?
